You’ll find keys all the time while looting in ROB RUN. Each one opens something specific, usually a room or safe with better loot than the rest of the building. Many new players sell them to the Fence without realising what they had.

## The four types of key

| Key          | Opens                                          | Where you find it                               |
| ------------ | ---------------------------------------------- | ----------------------------------------------- |
| **Safe Key** | One built-in safe in a named building          | Random loot, more often in **cabinets and storage rooms** |
| **Room Key** | One locked room in a named building            | Random loot, more often in **safes and lockers** |
| **Keycard**  | A restricted area, like a vault or armory      | Random loot                                     |
| **ID Card**  | Special big-heist areas, like the bank’s Gold Vault | Trades at Lenny’s Motel                   |

You **can’t buy** Safe Keys, Room Keys or Keycards. They only come from searching.

## How to use a key

1. **Read the key’s name.** It tells you the building, like “Safe Key (Reef Hotel)”.
2. **Go to that building.**
3. **Find the locked safe or room** and use the key.
4. Behind a locked room there’s often a **heavy safe**, which needs a **Mini Drill**, and a **computer** for your USB Hacking Tool.

## Where keys lead

Keys exist for most of the city’s targets, including:

- **Hotels:** the Seasons Hotel and Reef Hotel in Sunny Beach
- **Shops:** convenience stores, pharmacies, gun shops, equipment stores and electronics stores
- **The gas station** in Downtown, which has **two hidden rooms**
- **The Strip Club’s VIP room**
- **Cottages and the mansion** in Loraine Hills
- **Big targets:** the Police Station armory, the Art Gallery vault and the bank’s Gold Vault use Keycards and ID Cards

## No key? Use a tool

| Tool         | Opens without a key                              |
| ------------ | ------------------------------------------------ |
| **Lockpick** | Ordinary doors and containers, quietly           |
| **Mini Drill** | Heavy safes                                    |
| **Drill**    | The bank vault                                   |

See [every robbery tool in ROB RUN](/rob-run/robbery-tools).

## Tips

- **Don’t sell keys by mistake.** Check your bag before you sell everything to the Fence.
- **Use a key in the same session** if you can. Keys go back to being worthless at the wipe.
- **Bring a Mini Drill** when you use a Room Key: the safe behind the door usually needs one.
- **A good key can turn a small store into a big score.** It’s worth going back for.
