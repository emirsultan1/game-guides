# Screenshot list

Every spot in the ROB RUN guides that still needs a screenshot. Each one matches a
`[SCREENSHOT: ...]` line in the guide, which shows as a dashed box in `npm run dev`.

## How to take them

- **Key:** F12 in Steam saves a screenshot. Find them in Steam → View → Screenshots → Show on disk.
- **Resolution:** 1920×1080 if you can. Don't crop or resize — the site does that.
- **Clean shots:** hide the HUD and chat where the game lets you, and make sure no other player's name or chat is readable.
- **Menus:** for menu screenshots, open the menu fully so prices and stats are readable.
- **Send them** in a folder per guide (e.g. `first-hour-in-looty-bay/`). Any file names are fine; they'll be renamed.

**Total: 90 screenshots across 31 guides.** Start with the guides at the top — they're the ones most people will read first.
